# BrickView: Real Estate Analytics Platform

## Project Overview
BrickView is a real estate analytics platform built using Python, PostgreSQL, SQL, and Streamlit. It helps analyze property listings, sales trends, buyer behavior, and agent performance.

## Features
- Data cleaning and preprocessing using Python
- PostgreSQL database integration
- 30 SQL analytical queries
- Streamlit dashboard with filters
- KPI metrics
- Bar chart, pie chart, line chart, and map
- SQL query display section
- CRUD operations for agents

## Tech Stack
- Python
- Pandas
- PostgreSQL
- SQLAlchemy
- Streamlit
- Plotly

## Files
- `BrickView.ipynb` : Data loading, cleaning, and SQL queries
- `app.py` : Streamlit dashboard
- `requirements.txt` : Required Python libraries
